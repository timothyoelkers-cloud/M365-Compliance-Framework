What's new

One-click deploy is now live for Defender for O365 and Purview.

Previously these policy types required generating a PowerShell script and running it manually. A new server-side deployment proxy now forwards REST InvokeCommand calls from your browser straight to Microsoft, with your delegated token.

  • Click Deploy on any Defender, Exchange Online, or Purview policy.
  • The Deploy button works for SharePoint admin settings too — 9 SPO policies routed via Graph.
  • Anything still PS-only opens Deploy in Cloud Shell — script copied, shell opens in a new tab.

Your bearer token transits the proxy but is never logged or stored. CORS is locked to this site only. See Connect Tenant → Deployment Proxy to override or self-host.
